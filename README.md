# Projeto Calculadora

## Descrição
Calculadora simples desenvolvida em Java que realiza operações matemáticas básicas.

## Objetivo
Atividade prática para aplicar conceitos de orientação a objetos, documentação JavaDoc e versionamento com Git.

## Tecnologias Utilizadas
- Java
- Apache NetBeans
- Git / GitHub

## Operações Disponíveis
| Código | Operação       |
|--------|----------------|
| 1      | Adição         |
| 2      | Subtração      |
| 3      | Multiplicação  |
| 4      | Divisão        |
